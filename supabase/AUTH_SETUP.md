# 구글 계정 연결·로그인 설정 (한 번만)

앱 코드는 이미 들어 있다. 아래 설정을 마쳐야 버튼이 동작한다. (약 15분)
설정 전에 버튼을 누르면 "구글 로그인이 아직 설정되지 않았어요" 같은 안내가 나온다.

- **연결**: 지금 쓰는 임시(익명) 계정에 구글을 붙인다. 같은 계정이라 이름·불씨·꾸미기가 그대로 남는다.
- **로그인**: 이미 구글을 붙여 둔 계정으로 들어간다. 새 컴퓨터나 앱 데이터를 지운 뒤 이어 쓸 때 쓴다(처음 화면의 "이미 계정이 있어요").
- 구글 이메일은 Supabase 인증 정보에만 저장되고 친구에게는 보이지 않는다(프로필에는 이름만 있다).

## A. 구글 클라우드 콘솔 (https://console.cloud.google.com)

1. 새 프로젝트를 만든다(이름: 개릿).
2. **Google Auth Platform → 시작하기**(옛 화면은 *API 및 서비스 → OAuth 동의 화면*)
   - 앱 이름: 개릿 / 사용자 지원 이메일: 내 이메일
   - 대상: **외부** / 연락처 이메일: 내 이메일 → 만들기
   - 범위(scope)는 기본(openid, email, profile)이면 충분하다. 추가하지 않는다.
3. **대상(Audience)** 화면
   - 게시 상태가 **테스트**이면 **테스트 사용자**에 로그인할 사람(나·친구)의 구글 이메일을 추가해야 한다(최대 100명).
   - 사람이 늘면 **프로덕션으로 게시**한다(기본 범위만 쓰므로 별도 심사는 필요 없다).
4. **클라이언트 → 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션** (※ "데스크톱 앱" 유형으로 만들면 리디렉션 URI 입력 칸이 없고 Supabase와 맞지 않는다. 잘못 만들었으면 새로 만든다)
   - **승인된 리디렉션 URI**: `https://cxsohlckaadmdqkhrzou.supabase.co/auth/v1/callback` 한 개를 추가한다(JavaScript 원본은 비워 둔다).
   - 만들면 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 복사해 둔다.

## B. Supabase 대시보드 (Authentication 메뉴)

5. **Sign In / Providers → Google**을 켜고 위의 클라이언트 ID·비밀번호를 붙여 넣고 저장한다. 그 화면에 보이는 *Callback URL*이 4번에 넣은 주소와 같은지 확인한다.
6. 같은 **Sign In / Providers** 화면의 **Allow manual linking**(수동 계정 연결 허용)을 **켠다**. (구글 연결 버튼이 쓰는 기능이다. 꺼져 있으면 "계정 연결 설정이 아직 켜져 있지 않아요"가 뜬다.)
7. **URL Configuration → Redirect URLs**에 아래 주소를 추가하고 저장한다. 주소를 **정확히** 써야 한다(`localhost`가 아니라 `127.0.0.1`).
   ```
   http://127.0.0.1:41729/callback
   ```
8. (이미 켜져 있음) **Anonymous sign-ins**는 계속 켜 둔다.

## C. 동작 확인

1. 앱 → 방 시트 아래 **내 상태** → **계정** → **구글 계정 연결하기** → 브라우저에서 구글 로그인 → "로그인이 끝났어요" 페이지 → 앱에 "구글 계정을 연결했어요".
2. Supabase SQL Editor로 확인(내 계정이 영구 계정이 되었는지):
   ```sql
   select u.id, u.is_anonymous, u.email, i.provider
   from auth.users u left join auth.identities i on i.user_id = u.id
   order by u.created_at desc limit 5;
   ```
   → 내 행의 `is_anonymous = false`, `email`이 채워지고 `provider = google`이어야 한다.
3. **복구 확인(중요)**: 앱 데이터를 지우거나 다른 컴퓨터에서 처음 화면 → **이미 계정이 있어요(구글로 로그인)** → 이전 이름·불씨·꾸미기가 그대로 돌아오는지.
4. 이미 연결된 구글로 다시 "연결"을 누르면 "이미 다른 개릿 계정에 연결돼 있어요… '구글로 로그인'을 눌러 주세요"가 뜬다.

## 문제 해결

| 증상 | 원인 |
|---|---|
| "구글 로그인이 아직 설정되지 않았어요" | 5번(Google 제공자 켜기) 누락 |
| "계정 연결 설정이 아직 켜져 있지 않아요" | 6번(Allow manual linking) 누락 |
| 구글 화면에서 `redirect_uri_mismatch` | 4번의 승인된 리디렉션 URI 오타(Supabase Callback URL과 똑같아야 함), 또는 클라이언트 유형이 "데스크톱"이라 URI 칸이 아예 없음 |
| 구글 화면에서 `access_denied` / "앱이 확인되지 않음" 후 차단 | 3번(테스트 사용자 추가 또는 프로덕션 게시) |
| 로그인 후 브라우저가 이상한 주소로 감 | 7번(Redirect URLs) 누락 또는 `localhost`로 잘못 씀 |
| "로그인용 포트(41729)를 열 수 없어요" | 다른 프로그램이 그 포트를 쓰는 중이거나 이전 로그인 창이 3분 이내로 남아 있음 — 잠시 뒤 다시 |
| 3분 안에 로그인을 못 마침 | "로그인 시간이 지났어요" — 버튼을 다시 누른다 |

## 알아둘 점

- **연결은 꼭 미리 해 두자.** 연결하지 않은 임시 계정은 앱 데이터를 지우거나 컴퓨터를 바꾸면 되찾을 수 없다.
- 로그인(계정 바꾸기)을 하면 지금 컴퓨터의 임시 계정 진행 상황은 사라지고 연결해 둔 계정으로 바뀐다(확인 단계가 있다).
- 로그인 콜백은 이 컴퓨터의 `127.0.0.1:41729`에서 한 번만 받고(최대 3분) 닫힌다. 바깥에서는 접근할 수 없다.
