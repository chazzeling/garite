# 도트 그림 가이드

PNG를 이 폴더에 **아래 이름으로 넣기만 하면** 앱이 자동으로 씁니다(코드 수정 없음).
파일이 없는 것은 임시 표시(이모지·글자)로 나오므로, 완성된 것부터 하나씩 넣어도 됩니다.

## 기본 규칙

| 항목 | 규칙 |
|---|---|
| 형식 | PNG, **투명 배경**, 안티앨리어싱·번짐 없이(도트는 경계가 딱 떨어지게) |
| 크기 | **확대하지 않은 원본 크기**로 저장. 앱이 정수 배율(×2)로 키워 보여줍니다 |
| 방 그림 | **150×156** → 화면 300×312 (정확히 2배). 방은 **지붕(다락방) 모양**으로 위쪽 두 모서리가 잘려 투명해집니다 — 그림은 사각형 전체로 그려도 되지만, 윗변은 x 50~100(그림 기준), 처마는 y 44 아래로 보이니 천장·창문 그림은 그 안쪽에 두세요 |
| 캐릭터 | **16×16** 한 칸. **발이 아래 가운데**에 오게 그리기(좌석 위치가 발 기준). 모든 겹침 층이 같은 16×16 캔버스를 씁니다 |
| 팔레트 | 16~32색 권장, 외곽선 1px, 빛은 왼쪽 위에서 |
| 도구 | Aseprite(유료), LibreSprite·Piskel(무료). 프레임 여러 장은 **가로로 이어 붙인 한 장**으로 내보내기 |

## 캐릭터는 층을 겹쳐 그립니다 (꾸미기)

아래→위 순서로 겹쳐 보여줍니다: **몸 → 옷 → 머리 → 악세서리**.
같은 16×16 캔버스에 **같은 자리 기준**으로 그리면 어떤 조합이든 딱 맞습니다.

### 색 입히기: 몸·옷·머리는 "회색조"로 그리세요
- 몸, 옷, 머리는 **회색조(흰색~검정 사이)** 로 그립니다. 가장 밝은 곳이 하이라이트, 어두운 곳이 그림자입니다.
- 앱이 사용자가 고른 색(피부색·머리색·옷색)을 **곱해서** 입힙니다. 그래서 그림 한 벌로 색이 여러 가지가 됩니다.
- 흰색(#fff)에 가까울수록 고른 색이 그대로 나오고, 어두울수록 어둡게 나옵니다. 몸·머리는 밝은 회색(약 #e0~#fa)을 기본으로 쓰는 것을 권합니다.
- **악세서리는 색을 입히지 않습니다.** 원하는 색으로 직접 칠해서 그리세요.
- 눈·입처럼 색이 변하면 안 되는 부분은 몸 그림에 어두운 회색으로 그리면, 피부색이 곱해져도 어두운 점으로 보입니다.

### 파일 이름

```
characters/body/stand.png                16×16   서 있는 몸 (피부색이 입혀짐)
characters/body/sit.png                  16×16   앉은 몸
characters/body/lie.png                  16×16   누운 몸
characters/body/sit-typing@2.png         32×16   앉아서 타자 (프레임 2장) — 몸에만 프레임을 둡니다
characters/body/sit-drawing@2.png
characters/body/lie-typing@2.png

characters/hair/<머리id>/<자세>.png      16×16   머리 모양 (자세마다 한 장, 정지 그림)
characters/outfit/<옷id>/<자세>.png      16×16   옷 (필요하면 <자세>-<모션>@N.png 도 가능)
characters/accessory/<악세서리id>/<자세>.png  16×16   악세서리 (색 입히기 없음)
```

- `<자세>` = `stand`, `sit`, `lie`. 해당 자세의 그림이 없으면 그 층은 그냥 생략됩니다(일부만 그려도 동작).
- `<머리id>`·`<옷id>`·`<악세서리id>` 는 `config/items.json` 의 id 입니다:

| 종류 | id |
|---|---|
| hair | hair-short, hair-long, hair-bob, hair-twin, hair-bun |
| outfit | outfit-tee, outfit-hoodie, outfit-overalls, outfit-dress |
| accessory | acc-glasses, acc-ribbon, acc-hat, acc-headphones |

- 새 머리·옷·악세서리를 추가하려면 `items.json` 에 한 줄(id, 이름, 카테고리, 해금 레벨, 가격)을 넣고 **같은 내용을 새 마이그레이션의 `item_catalog`** 에도 넣습니다(`node scripts/check-catalog.mjs` 로 일치 확인). 그림 폴더에 id 이름으로 PNG를 넣으면 끝입니다.
- 색 팔레트(피부 6, 머리 12, 옷 12)는 `config/avatar.json` 에서 바꿀 수 있습니다.

### 작업량 가늠 (머리 5종 · 옷 4종 · 악세서리 4종 기준)
- 몸: 3자세 + 모션 3개(각 2프레임) = **그림 6장**
- 머리: 5종 × 3자세 = 15장 (누운 자세는 서 있는 머리를 돌려 그려도 됩니다)
- 옷: 4종 × 3자세 = 12장, 악세서리: 4종 × 3자세 = 12장
- 처음에는 **몸 + 기본 머리 1종 + 기본 옷 1종**만 그려도 꾸미기 틀 전체를 확인할 수 있습니다.

## 그 밖의 파일

```
room/background.png                 150×156   방 배경(벽+바닥)
room/background-1.png … -5.png      150×156   (선택) 방 조명 단계별 배경: 1 촛불 · 2 전구 · 3 전등 · 4 샹들리에 · 5 별빛. 없는 단계는 background.png를 씁니다
faces/default.png                   16×16     얼굴(멤버 목록·미니 모드)
overlays/idle.png                   8×8       "쉬는 중" 표시(머리 위에 얹음)
overlays/away.png                   8×8       "자리 비움" 표시
items/<아이템id>.png                슬롯 크기  가구·소품 (아래 표)
characters/default/<자세>.png       16×16     (선택) 층 없이 통으로 그린 캐릭터 — 층 그림이 없을 때 대신 사용
```

- 파일명 끝 `@N` 은 **프레임 수**입니다(`sit-typing@2.png` = 프레임 2장, 0.25초 간격 반복).
- **작업 중 / 쉬는 중 / 자리 비움은 캐릭터를 따로 그리지 않습니다.** 쉬는 중·자리 비움은 `overlays/`의 8×8 아이콘이 머리 위에 얹힙니다.

## 가구 크기 (같은 카테고리는 크기가 같음)

`config/slots.json` 의 `w`×`h` 가 그림 크기입니다. 크기를 바꾸고 싶으면 그 파일의 숫자를 고치면 됩니다.

| 카테고리 | 크기 | 아이템 id |
|---|---|---|
| bed | 41×41 | bed-basic, bed-quilt |
| desk | 38×37 | desk-basic, desk-wood |
| shelf | 24×37 | shelf-basic |
| deco | 14×14 | deco-plant, deco-lamp |
| rug | 49×34 | rug-basic, rug-round |

위치(좌표)는 `config/slots.json`, 앉는 자리는 `config/seats.json` 에 있습니다(둘 다 150×156 그림 기준 픽셀).
캐릭터가 어색하게 앉아 있으면 `seats.json` 의 `x`,`y`(=발 위치)만 조금씩 옮기면 됩니다.

## 만드는 순서 (권장)

1. 팔레트·외곽선 규칙 정하기
2. 방 배경 1장
3. 몸 3자세 (stand, sit, lie) — **회색조**로
4. 기본 옷(outfit-tee)·기본 머리(hair-short) 3자세씩 — **회색조**로
5. 레벨 1 무료 가구 3개 (bed-basic, desk-basic, rug-basic)
6. 얼굴 아이콘, 상태 아이콘(idle, away)
7. 움직임 프레임: body/sit-typing, sit-drawing, lie-typing 각 2프레임
8. 나머지 머리·옷·악세서리, 나머지 가구

## 겹침 순서

- 방 안 겹침은 슬롯의 `z` 값으로 고정(러그 1 < 선반 5 < 소품 6 < 침대 10 < 책상 20). 캐릭터는 앉은 가구보다 한 칸 위입니다.
- 그래서 책상 그림은 **의자·책상이 비어 있는 상태**로 그리고, 앉은 캐릭터가 그 위에 얹힌다고 생각하고 그리세요.
