개인정보처리방침

개릿(이하 "앱")은 친구들과 작업 상태를 나누는 앱이에요. 앱이 어떤 정보를 어떻게 쓰는지 아래에 적었어요. 시행일: 2026-10-16

1. 수집하는 정보

  • 구글 계정 정보(이메일): 구글로 로그인·연결할 때만 받아요. 로그인 확인에만 쓰고, 다른 사용자에게 보이지 않아요.
  • 프로필: 사용자가 정한 이름과 캐릭터 꾸미기 값. 같은 방에 있는 사용자에게 보여요.
  • 작업 상태: 작업 중 / 쉬는 중 / 자리 비움, 직접 적은 상태 문구, 집중 모드 여부. 같은 방 사용자에게 실시간으로 공유돼요.
  • 작업 시간 기록: 작업으로 인정된 시간을 분 단위로 기록해 불씨(재화)와 통계에 써요.
  • 채팅 메시지: 방별 최근 200개까지만 보관하고, 방을 새로 만들거나 닫으면 삭제돼요.
  • 프로그램 이름(선택): 사용자가 앱 안 동의 창에서 허락한 경우에만 지금 보고 있는 프로그램의 이름을 읽어요. 공유는 설정에서 끌 수 있고, 끄면 다른 사람에게 보내지 않아요. 브라우저 탭 제목이나 화면 내용은 읽지 않아요.

2. 수집하지 않는 정보

화면 캡처, 키보드로 입력한 내용, 파일 내용, 위치 정보는 수집하지 않아요. 입력 감지는 "마지막 입력 시각"과 키보드/마우스 구분만 사용하고 어떤 키인지는 읽지 않아요.

3. 이용 목적

방 공유, 채팅, 작업 시간 계산, 아이템 해금 등 앱의 기능을 제공하는 데에만 써요. 광고에 쓰거나 제3자에게 판매하지 않아요.

4. 저장 위치와 제공

데이터는 서비스 제공업체 Supabase의 서버에 저장돼요. 법령에 따른 요청이 아니라면 제3자에게 제공하지 않아요. 앱 업데이트 확인은 GitHub를 통해 이루어져요.

5. 보관과 삭제

계정 정보와 작업 기록은 계정이 유지되는 동안 보관해요. 삭제를 원하면 아래 문의처로 요청해 주세요. 요청을 확인한 뒤 계정과 관련 기록을 삭제해요.
