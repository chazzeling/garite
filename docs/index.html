개릿 (garite)

친구들과 같은 방에 모여 작업하는 가벼운 데스크탑 앱이에요. 감시가 아니라 "내가 지금 작업 중"이 자연스럽게 보여서 스스로 집중하게 되는 것, 그리고 보는 재미가 목적이에요.

  • 방 코드로 친구가 입장하면 캐릭터가 작업 중 / 쉬는 중 / 자리 비움을 보여줘요.
  • 작업한 시간만큼 불씨가 쌓이고 방이 점점 환해져요.
  • 채팅, 찌르기, 하루 작업 목표 보너스.
  • 화면 공유와 스크린샷은 없어요.

Windows · macOS 지원. 설치 파일은 Releases에서 받을 수 있어요.
